I spent 100 hours building this 2d space platformer using Godot. Excluding the games I created on Scratch during the pandemic, this was the first "real" game I developed. I created this as part of Juice, a hackathon. I created all the art, and improved my animation skills, on Aesprite. My game won a Popular Award, the top three games selected by judges from, in Shanghai.
